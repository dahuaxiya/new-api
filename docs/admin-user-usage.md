# 管理员用户用量总览

管理员打开 `/user-usage`，或从「管理 → 用户用量总览」进入。

- 每页 10 个用户，默认统计近 7 天，可切换近 24 小时、近 30 天。
- 所选时段：请求数、Token 数、站内消耗。复用 `/api/data/users` 的已保存汇总，按 username 聚合；可能晚于使用日志。用户名修改前的历史数据仍属于旧用户名，不会自动迁移到新用户名。
- 累计请求数、累计站内消耗和余额：复用管理员用户列表。
- GPT 5 小时和 7 天窗口：显示绑定账号的官方剩余比例、已用比例、重置时间和读数时间。未绑定、未返回窗口、窗口过期、同步失败分别呈现，不将未知数据当成满额。
- 「查看使用日志」携带对应用户名和所选时段跳转。汇总 API 使用 Unix 秒，日志页面路由使用毫秒。
- 「刷新显示」重新读取用户、用量和已保存官方读数；官方读数显示每 30 秒刷新一次，不批量触发官方探测。原有普通用户页的「刷新官方额度」行为保持不变。

本站用量只包含经过 New API 的请求。直接调用 vm2api 或使用 ChatGPT/Codex 其他客户端产生的消耗，不进入本站日志，但会影响官方订阅额度。官方订阅百分比和站内计费单位无法直接互相换算。

## 访问边界

新增 `GET /api/gpt-quota/users/:id`：

1. 通过现有 AdminAuth 验证有效会话及当前管理员角色；控制器再次校验角色。
2. 可选 `New-Api-User` 必须是当前操作者，而不是目标用户。
3. 目标只能是正整数用户 ID；拒绝额外查询参数。读取目标当前数据库身份，按 ID、用户名、分组匹配既有固定绑定。
4. 已删除/不存在用户返回 404；未绑定返回 bound=false；查询不可用返回 503。只返回安全的额度视图，不返回代理信息、槽位凭据或用户密码。
5. 使用 no-store/private；前端按操作者及会话隔离缓存，切换到普通账号立即卸载管理视图。仅隐藏菜单不构成授权控制。

实现复用了已有模型读取及统计接口，没有数据库结构、SQL、计费或账号绑定变更。

## 验证与参考

- 后端：真实 AdminAuth 中间件，普通用户/匿名/伪造凭据被拒绝，管理员可读；目标 ID、身份提示、查询参数、已删除用户、目标分组变化、注销及禁用检查。
- 前端：用户汇总匹配、缺失窗口、未绑定、读取失败、切换账号清除内容、时间范围、日志跳转单位、刷新不发送探测、中文资源，以及原个人额度页的手动刷新回归。
- UI 复用 SectionPageLayout、Card、Button、Select、Pagination、Empty、ErrorState 和既有官方窗口组件，未新增依赖或通用控件。
- 授权设计参考 OWASP ASVS 5.0.0 V8.1.1、V8.2.1–V8.2.3、V8.3.1–V8.3.2，以及 Authentication、Session Management、Authorization Cheat Sheets。验证范围是本功能的访问边界，不代表整个产品通过 ASVS 认证。
