# 用户门户精简说明

参照黑鱼用户中心的功能分组，使用本站现有 shadcn 组件与品牌设计，不复制参考站品牌、布局或私有数据。

## 用户页面

- 仪表盘：当前登录账号的站内余额、累计消耗、请求数、密钥总数；按 1 / 7 / 30 天查看用量图表和最近五条消费记录；显示本站 API 接入地址。
- GPT 官方额度：保留 5 小时 / 7 天读数、过期或未知状态、手动探测与原有自动更新，在首页与密钥页可见。
- API 密钥、使用日志：沿用原有数据和操作。
- 账单与兑换：充值、兑换和账单历史沿用原有接口，邀请返利单独放在页内标签。
- 个人设置：资料、语言及原有安全与访问页面。移除签到、用户自定义侧栏面板。
- 顶部保留模型广场和本站接入教程；公告、语言和明暗主题仍可用。

移除聊天、游乐场、任务日志、排行榜、布局调试入口及默认首页的营销统计。旧聊天/任务日志书签回到用户首页，排行榜转到模型广场。非管理员的旧高级分析页面也回到用户首页。未新增发票、AI 图片/视频工作站或未配置的支付能力。

## 管理工作区

管理员在用户中心只看到一个“管理后台”入口。进入后侧栏切换为用户、用量总览、使用/审计日志、渠道、模型、兑换码、订阅与系统配置。系统设置可返回后台，后台可返回用户中心。服务器鉴权和原有角色约束不变，工作区菜单仍应用后台可见性配置。

用户首页即使由管理员访问，也使用 /api/user/self、/api/data/self、/api/log/self 和个人 token 元数据接口；全站数据从管理后台查看。查询缓存按用户和会话隔离，不读取明文 API Key。站内用量刷新与官方额度刷新为两个明确动作。
